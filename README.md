# Schlank ohne Verzicht – Quiz Funnel Landingpage

Landing page de alta conversão (quiz funnel direto) para o produto de emagrecimento digital **"Schlank ohne Verzicht"** (Digistore24).

## 🚀 Recursos
- **Funil de Quiz Interativo (6 Perguntas)** com transições suaves e cálculo de perfil de metabolismo.
- **Tela de Análise Interativa:** Carregamento psicológico de 3 segundos que analisa respostas e gera grande antecipação e valor percebido.
- **Oferta de Alta Conversão (Direct-Response):**
  - Empilhamento de valor (Value Stack com 3 bônus exclusivos).
  - Cronômetro regressivo ativo de escassez (14:59 min).
  - Garantia incondicional de 60 dias com selo de confiança.
  - Prova social com depoimentos e métricas de emagrecimento.
  - Acordeão FAQ para quebra de objeções.
- **Imagens Publicitárias:**
  - Hero image fotorrealista (`hero.jpg`).
  - Prova visual de transformação antes/depois (`transformation.jpg`).
  - Mockup 3D do pacote digital (`bundle_mockup.jpg`).
- **Integração Digistore24:** Links de afiliado configurados nos botões de checkout.

## 🛠️ Como Executar Localmente
```bash
python3 -m http.server 8000
```
Acesse [http://localhost:8000](http://localhost:8000) no seu navegador.

## 🌐 Publicação no GitHub Pages
1. Acesse o repositório no GitHub.
2. Vá em **Settings** > **Pages**.
3. Em **Branch**, selecione `main` e a pasta `/ (root)`.
4. Salve para disponibilizar o site publicamente online.
